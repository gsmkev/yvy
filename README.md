# Capturas del rediseño de UI de Yvy

Rama solo de capturas (sin código, no se mergea). El trabajo está en `claude/ui-refactor`.

| Carpeta | Qué hay |
|---|---|
| `web/antes` | La web antes del rediseño (organización demo). `d-` escritorio 1440 px, `m-` celular 390 px |
| `web/despues` | Las mismas pantallas después del rediseño |
| `web/estados` | Pestañas, modales y menús revisados en el pulido |
| `web/manual` | La web con una organización de ejemplo con datos cargados (material del manual, en curso) |
| `app/*` | La app corriendo en el navegador (vista web de Expo), por tanda de trabajo; `lote` y `hacienda` están en curso |

El mapa de la app no se ve en estas capturas: la vista web usa otro motor que el teléfono.
